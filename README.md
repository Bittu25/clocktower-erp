# Clocktower: BITS ERP concept

A concept redesign of the BITS student ERP and student life cycle.

- `index.html`: design notes (audit of today's systems, 12-stage student life cycle, patterns borrowed from apps students use, flow checks, rollout plan)
- `app.html`: the clickable student app prototype (Today, Academics, Campus, Wallet, Inbox) with sample data

Open either file in a browser. Light theme by default, with a dark mode switch.

Not affiliated with or endorsed by BITS Pilani. Names, marks and amounts are illustrative; nothing connects to real systems or moves money.

# Clocktower: BITS ERP concept

A concept redesign of the BITS student ERP and student life cycle: audit of today's systems, the 12-stage life cycle, patterns borrowed from apps students already use, a clickable phone prototype, before/after flow checks, and a rollout plan.

Open `index.html` in a browser, or view the live page via GitHub Pages.

Not affiliated with or endorsed by BITS Pilani. Names, marks and amounts in the prototype are illustrative.
